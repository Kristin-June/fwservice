## 多设备使用

1. 各设备使用同一个 ChatGPT 账号和工作区
2. 在 ChatGPT 的 Settings > Codex Cloud > Environments 中创建环境，并选择本仓库
3. 检查环境设置与验证结果，确认后发布
4. 切换设备时继续同一个云端任务；新任务拥有独立的工作文件
5. 需要保留到仓库的成果应提交到 Git，并推送到对应分支

本地文件和本地任务不会因连接 GitHub 而自动迁移至云端
